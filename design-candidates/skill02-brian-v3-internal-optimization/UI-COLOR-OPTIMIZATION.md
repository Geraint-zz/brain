# Brain v3 color optimization

## Updated palette

| Role | Color | Purpose |
|---|---|---|
| Paper canvas | #F8F7F2 | Warm long-form reading background |
| Deep teal ink | #123B3A | Wordmark, primary action, headings |
| Teal container | #1B4C4A | Stable dark surfaces and navigation |
| Mist sage | #E7EEE8 | Cards and low-emphasis sections |
| Soft sage | #DCE8E1 | Supporting surface differentiation |
| Terracotta | #B75D45 | Restrained emphasis and focus state |
| Dark body text | #172422 | High-contrast reading text |
| Muted text | #4B5E58 | Secondary metadata without cold grey |

The palette remains editorial rather than clinical: dark teal supplies trust, paper and sage reduce visual fatigue, and terracotta draws attention without becoming a sales signal. Existing visual-architecture limitations and asset-localization requirements remain unchanged.
